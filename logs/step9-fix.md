# Step 9 日志 - 空白页面 Bug 修复

## 问题现象

前端页面显示完全空白，控制台 JS 报错，整个应用无法渲染。

## 问题排查

逐文件检查上次修改的代码，定位到 `src/utils/llm.js` 中 `buildSystemPrompt()` 函数。

## 根因

System Prompt 字符串是 JavaScript **模板字符串**（反引号 `` ` `` 包裹），但 Prompt 内容中包含了 markdown 代码块标记 `` ```json `` 和 `` ``` ``：

```js
// ❌ 错误：反引号嵌套导致 JS 解析失败
return `你是一个专业的绘图指令解析器...
...
```json     // ← 这里的三反引号被 JS 当做模板字符串结束符
{"action":...}
```         // ← 同理
...`
```

浏览器在解析 `llm.js` 时，遇到 Prompt 内部的 ` ``` ` 就认为模板字符串已结束，后续内容变成无效语法，导致整个模块加载失败 → Vue 组件无法挂载 → 页面空白。

## 修复方案

移除 System Prompt 中两个 JSON 示例代码块周围的 ` ```json ` / ` ``` ` 标记，保留纯 JSON 内容。

LLM 不需要 markdown 格式提示，纯 JSON 示例同样能正确理解。

## 涉及文件

| 文件 | 修改 |
|------|------|
| `src/utils/llm.js` | 移除 System Prompt 中示例代码的反引号包裹 |

## 预防措施

未来在 JS 模板字符串中嵌入代码示例时，应避免使用反引号，改用缩进或纯文本标注。
