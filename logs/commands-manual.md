# 🎨 AI 语音绘图 - 指令手册

> 配置好 DeepSeek API 后，LLM 智能引擎让以下指令都能被正确解析执行。

---

## 一、基础绘图指令

### 单图形绘制
| 语音指令示例 | 效果 |
|-------------|------|
| "画一个红色的圆" | 画布中心红色圆 (radius≈80) |
| "画一个大大的蓝色正方形" | 画布中心大号蓝色正方形 |
| "画一个绿色三角形" | 画布中心绿色三角形 |
| "画一条黑色直线" | 从左到右的水平线 |
| "写一段文字你好世界" | 画布中心显示文字 |
| "画一个半透明的黄色圆形" | 带透明度的黄色圆 |

## 二、复杂组合指令 (LLM batch 自动拆解)

| 语音指令 | LLM 拆解逻辑 |

| "画一个笑脸" | 黄色大圆(脸) + 两个小黑圆(眼) + 弧线(嘴) |

| "画一棵树" | 棕色矩形(树干) + 绿色大三角(树冠) |

## 七、画布上有多图形时的交互

当画布上有多个图形，你发出模糊指令时，AI 会通过 **TTS 语音反问** 让你确认：

| 你说 | 画布状态 | AI 语音回复 |
|------|----------|------------|
| "把它变红" | 有3个图形 | "画布上有3个图形，请问您想把哪个变成红色？" |
| "删除它" | 有2个图形 | "画布上有2个图形，请问您要删除哪一个？" |
| "把它变大" | 有4个图形 | "画布上有4个图形，请问您想把哪个变大？" |

此时你可以接着回答：
- "红色的那个" / "圆形" / "第一个"
- "第二个"
- "全部"

## 十、技巧与提示

1. **顺序描述**：先说动作，再说对象，最后说属性。如"画一个大大的红色圆"比"红色的大大圆画一个"效果好
2. **先简单后复杂**：先画基础图形，再逐一修改配色和位置
3. **分步创作**：复杂场景可以分多句说，比如先说"画一个房子"，再说"在房子旁边画一棵树"
4. **利用追问**：不确定时直接用模糊指令，让 AI 追问后你再确认
5. **文字输入备用**：如果环境嘈杂语音不准，可以用右下角文字输入框打字
