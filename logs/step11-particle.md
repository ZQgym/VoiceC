## 实现详情

### 粒子系统核心参数

| 参数 | 值 | 说明 |
|------|:--:|------|
| 粒子数量 | 90 | 全屏漂浮粒子 |
| 粒子尺寸 | 3~7px | 带白色核心 + 彩色光晕 |
| 光晕半径 | size × 4 | 径向渐变从实心到透明 |
| 连线距离 | 180px | 近距离粒子自动连线 |
| 连线透明度 | 0.55 | 基础透明度，靠近鼠标时提升至 0.85 |
| 混合模式 | `lighter` | 叠加发光，重叠区域更亮 |
| 鼠标吸引半径 | 150px | 光标范围内的粒子被吸引靠近 |

### 交互功能

| 交互 | 效果 |
|------|------|
| **鼠标移动** | 粒子被光标吸引靠近，靠近的粒子放大、连线变亮 |
| **鼠标移出** | 粒子恢复自由漂浮状态 |
| **点击画面** | 粒子从点击位置向外爆发扩散 (200px 范围推力)，同时在点击位置生成 10 个金/橙/红色火花粒子，1.8 秒后自动回收 |

### 颜色方案 (第三次迭代)

经过三轮调整，最终使用亮霓虹色系以确保在深色背景上清晰可见：

- `#818cf8` 亮靛蓝
- `#a78bfa` 亮紫
- `#c084fc` 亮粉紫
- `#38bdf8` 天蓝
- `#22d3ee` 青
- `#f472b6` 粉色

爆裂粒子颜色：`#fbbf24`(金) / `#f97316`(橙) / `#ef4444`(红)

### 绘制技术

- **globalCompositeOperation = 'lighter'**: 颜色值叠加而非覆盖，粒子重叠区域自然发亮
- **白色实心核**: 每个粒子中心为纯白，外层渐变彩色光晕，形成霓虹灯效果
- **Canvas DPR 适配**: 支持高 DPI 屏幕 (`window.devicePixelRatio`)
- **边界环绕**: 粒子超出屏幕后从对侧重新进入

## 视觉层级

```
z-index: 0  → ParticleBackground (fixed, 全屏)
z-index: 1  → .app-container (relative)
              ├── .canvas-area (rgba(255,255,255,0.85) + backdrop-blur 4px)
              └── .control-panel (rgba(255,255,255,0.88) + backdrop-blur 6px)
```

粒子作为最底层背景，画布和控制面板通过毛玻璃半透明效果浮在其上，粒子可在面板间透过可见。
